# SmartWork Hub API (เริ่มต้น)

Base URL สำหรับพัฒนา: `http://localhost:8000/api`

คำตอบและ request body ใช้ JSON; endpoint ที่ต้องยืนยันตัวตนรับ `Authorization: Bearer <token>`

| Method | Path | การใช้งาน | ยืนยันตัวตน |
|---|---|---|---|
| GET | `/health` | ตรวจสอบว่า API ทำงาน | ไม่ |
| POST | `/login` | เข้าสู่ระบบด้วย email/password | ไม่ |
| GET | `/me` | อ่านข้อมูลผู้ใช้ปัจจุบัน | ใช่ |
| POST | `/logout` | เพิกถอน token ปัจจุบัน | ใช่ |

ตัวอย่างเข้าสู่ระบบ:

```json
{
  "email": "admin@example.com",
  "password": "your-password"
}
```

เมื่อสำเร็จ API ส่ง `token`, `token_type`, `expires_at` และ `user` กลับมา ค่า token ดิบแสดงครั้งเดียวและไม่ถูกบันทึกในฐานข้อมูล ให้เก็บ token อย่างระมัดระวังและส่งกลับเป็น Bearer token ใน request ถัดไป

รหัสสถานะหลัก: `400` JSON ไม่ถูกต้อง, `401` ไม่ผ่านการยืนยันตัวตน/ข้อมูล Login ไม่ถูกต้อง, `404` ไม่พบ route, `405` method ไม่รองรับ, `422` ข้อมูล Login ไม่ครบหรือรูปแบบไม่ถูกต้อง และ `500` ข้อผิดพลาดภายใน

เส้นทางจัดการพนักงาน, งาน, ลงเวลา, ประกาศ, แจ้งเตือน, โปรไฟล์ และรายงานยังไม่ได้เปิดใช้งานในโครงเริ่มต้นนี้

Middleware `AuthorizeRole` เตรียมไว้ให้ route ของโมดูลเหล่านั้นกำหนด role ที่อนุญาตได้ แต่ยังไม่มี endpoint ที่บังคับสิทธิ์ในรุ่นเริ่มต้น
